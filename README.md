# Newton Unlock for Mac OS 9

A classic Mac OS version of the Newton Unlock app, drawn to look like a Newton
OS application. Pick a game from the ◆ Game picker, type the registration code
or owner name on the dotted line, and the unlock code appears. **Copy** (or
Return) puts it on the clipboard; the **i** button shows the About box and the
close box in the corner quits. Drag the window by any empty part of it.

It's a PowerPC application for Mac OS 9 (built and intended for 9.2). It uses
only long-standing Toolbox calls, so it should also run on earlier PowerPC
systems and in Mac OS X's Classic environment, but those haven't been tried.

## Files

| File | What it is |
|---|---|
| `unlockers.c`, `unlockers.h` | The unlock algorithms, ported from the Python scripts in each game's folder. Plain C89, with no Mac-specific code. |
| `games.c` | The list of games: name, publisher, input type, salt and hint. |
| `main.c` | The Mac OS user interface: draws the Newton-style window with QuickDraw, plus menus, typing and clipboard. |
| `NewtonUnlock.r` | Resources: window, menus, version and Finder bundle. |
| `icons.r` | Finder icons, generated by `tools/make_icons.py` from the Newton logo. |
| `tests/check.py` | Compares the C algorithms with the Python scripts on thousands of inputs. |
| `tools/package.py` | Packages the build into `dist/` and sets the Finder flag that makes OS 9 show the app's own icon. |
| `dist/` | The finished app: `Newton Unlock.bin` (MacBinary) and `Newton Unlock.dsk` (800K disk image). |

## Building (Retro68)

[Retro68](https://github.com/autc04/Retro68) is a cross-compiler for classic
Mac OS that runs on a modern Mac. This Mac has it in `~/Retro68-build`.

```
cd NewtonUnlockOS9
cmake -B build -DCMAKE_TOOLCHAIN_FILE=$HOME/Retro68-build/toolchain/powerpc-apple-macos/cmake/retroppc.toolchain.cmake
cmake --build build
python3 tools/package.py
```

The finished application is in `dist/`.

## Copying it to the OS 9 Mac

Either:

- **MacBinary:** copy `dist/Newton Unlock.bin` across using a USB stick, a file
  share or the web, then open it with **StuffIt Expander**. That turns it back
  into a normal application with its icon, type and creator intact.
- **Disk image:** `dist/Newton Unlock.dsk` is an 800K HFS floppy image holding
  the app. Mount it in an emulator such as SheepShaver, or write it to a
  floppy.

Don't copy the raw build output any other way: modern file systems drop the
classic resource fork, which holds all of the app's resources.

## Adding a game

1. Add a line to `gGames` in `games.c`.
2. Add the game to the `GAMES` list in `tests/check.py`, at the same position, and run it.

The picker list shows up to 16 games (two columns of 8); more would need a
bigger list in `main.c`.

For another Tactile Systems game, the new line is only a title and the
two-letter salt.

## Checking the algorithms

```
python3 tests/check.py
```

This builds `unlockers.c` with the Mac's own compiler and compares it with
the Python scripts. Expect `0 mismatches`.
